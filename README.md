# 游戏内服务发现与注册中心系统

## 项目描述

游戏内服务发现与注册中心系统的bug修复项目。核心模块 `service/registry.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 服务注册只设标志位不实际注册到注册中心
- 服务发现完全没做只能硬编码IP地址
- 心跳完全没做服务挂了也不注销
- 健康检查完全没做挂了的服务还在注册列表
- 服务注销完全没做服务下线了还在列表

## 运行测试

```bash
python -m pytest tests/test_registry.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
